UI/UX Interactive Showcase List Controller Specification

Unified Right-Aligned Controller & Delete Selection Mode

Demonstrating right-aligned search & menu, view toggle inside kebab menu, adaptive single-action vs multi-action (three dots) rule, combined filter & sort modal, and automatic switch to bulk delete mode upon item selection.

Presets:
1

Right-Aligned Controls

Search bar and menu/actions are placed on the right side of the list header, keeping titles prominent on the left.

2

View Toggle in Menu

List/Grid toggle is integrated directly inside the three-dots menu dropdown, reducing visual clutter on the toolbar.

3

Adaptive 3-Dots vs Single

If there is only 1 menu action, it renders as a direct button. If >1 action, it collapses into the 3-dots kebab menu.

4

Delete / Bulk Mode

Selecting any item instantly replaces the standard controller with Delete Mode (Select All, Delete, and Cancel buttons).
